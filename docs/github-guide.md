# **CYBER-TWIN — GitHub Team Guide**

This guide explains how the CYBER-TWIN team will use Git and GitHub. Every team member must read this guide before starting development.

Our goal is to prevent:
* Code conflicts  
* Accidental deletion of work  
* Broken `main` branch  
* Unclear commits  
* Duplicate work  
* Lost changes  
* Unreviewed code

---

## **Repository and Branches**

The repository has two permanent branches:
* `main`  
* `develop`  
* And individual feature branches for development

Our workflow is:
```text
                   main  
                     ↑  
                 Pull Request  
                     ↑  
                  develop  
                     ↑  
              Pull Request  
                     ↑  
             Feature Branch
